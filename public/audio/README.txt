Optional custom background music folder.

To add your own custom background song:
1. Place an MP3 file in this folder.
2. Name it "birthday-music.mp3" (i.e. public/audio/birthday-music.mp3).
3. The website will automatically detect and play it when the visitor clicks the Music button!

Note: If no MP3 is placed here, the website will automatically play a soothing romantic ambient chord synthesizer using the browser's native Web Audio API, so it always sounds magical out of the box!
